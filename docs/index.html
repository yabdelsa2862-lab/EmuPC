Get started

Tested on an iPhone 16 Pro Max (8 GB) and an iPad Air 4 (4 GB) on iOS 27. Other recent iPhones and iPads should work; 4 GB devices get a low-memory profile and run lighter games.

  1. Download the IPA

    From the Download section above, and check its SHA-256.

  2. Sideload it

    Use SideStore, AltStore or Sideloadly. With a free Apple ID, apps stay signed for 7 days, so refresh EmuPC in SideStore or AltStore before then (an expired copy says it's "no longer available").

  3. Add the memory permissions

    Use GetMoreRam to give EmuPC's App ID the increased memory limit and extended virtual addressing. Bigger games need them; the Memory+ badge turns green when they're on.

  4. Turn on JIT

    EmuPC needs JIT to run games. Use its built-in helper or StikDebug with LocalDevVPN; EmuPC's first-run setup walks you through it. Details: JIT setup.

  5. Sign in and play

    Sign in to your stores, download a game you own, and press Play.

Check your download

The SHA-256 is a fingerprint of the file. If yours matches the one shown in the Download section, it's the exact file from the official release.

Mac

In Terminal:

shasum -a 256 ~/Downloads/EmuPC-*.ipa

Windows

In PowerShell:

Get-FileHash $HOME\Downloads\EmuPC-*.ipa

FAQ

Is it free?

Yes. EmuPC is free and open source under the GPL-3.0 license. You only need to own the games you play.

Will every game run?

No. EmuPC is an experimental project. Many games start and some play well, but performance and compatibility vary from game to game, and the store shows an estimate for each one.

Do online games with anti-cheat work?

Usually not. Anti-cheat systems like Easy Anti-Cheat have no iOS version, so their online modes can't connect. EmuPC doesn't try to get around anti-cheat.

Why isn't it on the App Store?

Running PC games needs JIT, which the App Store doesn't allow for apps like this, so EmuPC is sideloaded.

It says "no longer available" when I open it

The app's signature expired. Refresh EmuPC in SideStore or AltStore, or sign and install it again. Your games and settings stay.

How do I report a problem?

Open an issue on GitHub and attach the files from Settings › Advanced › Get Help from Claude, so the log shows what happened.
